## 🛠️ Local Development & Build

### Prerequisites
*   Node.js (v18.x or newer, v20+ recommended)
*   npm (v9.x or newer)

### Installation
```bash
npm install --legacy-peer-deps
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run start
```

### Type Checking
```bash
npx tsc --noEmit
```
